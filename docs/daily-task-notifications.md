# 每日任务汇总

在「检查与提醒 → 每日任务汇总」中开启提醒，选择需要纳入汇总的任务，并设置最终汇总时间。默认时间为每天 23:55，采用 UTC+8。时间和任务开关统一通过「保存设置」保存。

当天自动任务全部结束后发送一次汇总。仍在等待开播、尚未到执行时间、执行失败或进度未完成的任务会继续等待。到最终汇总时间后，发送当天结果并列出失败次数和未完成账号。账号使用掩码显示。

每天最多发起一次任务汇总通知，发送记录保存到本地，重启后继续使用。到时间发送汇总不会中止正在执行的活动，后续轮次不会再次发送当天的汇总。手动执行、手动补做和自动补做不单独触发通知。

普通定时任务按当天最后一个计划执行时间及任务级执行记录判断是否结束，今天没有计划的任务不纳入。直播粉丝牌自动监测使用已有进度缓存，排除的主播不参与判断。官方任务完成或达到用户设置的每日执行额度后，视为当天自动活动结束。等待开播、进度缺失或过期时会保持待完成状态。

每日任务汇总和 Cookie 过期提醒共用已保存的 Server 酱 SendKey。Cookie 过期提醒保留每账号每天一次的规则。Web 面板的旧逐轮 Server 酱日志推送关闭，其他日志通道保持原配置。
