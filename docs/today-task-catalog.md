# 今日任务目录

今日任务与任务配置导航共用 `TaskCatalog`，按相同名称和顺序展示 10 个任务。检查与提醒是通知设置，不作为活动任务计入完成进度。

每日任务包含登录、观看视频、分享视频和投币四个检查项。大会员福利单独展示，使用 `VipPrivilegeConfig` 的开关、`VipPrivilegeJob` 的执行时间和 `VipPrivilegeTaskAppService` 的账号执行记录。关闭每日任务不影响已开启的大会员福利任务。每日任务的成功记录不代表福利任务已完成。

福利补做使用独立福利任务，并将结果与补做次数记在福利任务下。原有每日任务末尾的福利领取步骤仍按福利配置执行，历史记录不重新归类。

多账号默认展示第一个账号。点击左右箭头可循环切换，也可以通过账号选择器直接选择或展示全部账号。刷新进度后保留所选账号，选择的账号被移除后展示第一个可用账号。

查看单个账号时，顶部补做按钮只处理当前账号。选择全部账号时，该按钮处理所有账号。自动补做设置仍对所有账号生效。

## 手动补做反馈

单项、整卡和全部账号补做在点击后显示转圈提示及“补做中”。单项任务行展示本次执行状态，整卡与全部账号补做显示对应账号的处理提示。执行结束后显示“更新中”，刷新任务状态后保留本次结果。刷新前保持按钮禁用，完成后恢复操作。

批量结果显示本轮执行的项目数量，各项完成情况继续使用任务状态判断。没有需要执行的任务时显示“当前没有需要补做的任务”。执行异常和状态刷新异常都保留结果提示，后续可重新操作。手动补做使用现有页面反馈，不发送失败推送。
